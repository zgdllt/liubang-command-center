# 讲师手册

> 配套：`课程设计.md`、`学员手册.md`、`lab/`
> 目标：让一位没讲过这堂课的老师，也能在 30 分钟内准备好、90 分钟内讲完、下课后能复盘。

---

## 一、开课前检查

### T-7 天

- [ ] 确定形式：线下工作坊 / 直播 / 社团内训。
- [ ] 确定人数：实验 C 的裁判默认支持 2–6 人；超过 6 人分多桌，每桌一个裁判，或改用"大屏 + 举手"的简化版。
- [ ] 确定学员的 agent 情况：Claude Code / Codex CLI / Cursor / 只用聊天窗口。没有 agent 的人安排两人一组。
- [ ] 把 `lab/` 打包，准备二维码或短链接；`lab/facilitator/` 不要发。
- [ ] 打印 `学员手册.md`（一人一份）和"委托卡片"（一人三张，A6 大小）。

### T-1 天

- [ ] 在一台干净的机器上跑一遍三条验证命令（见 `README.md`）。
- [ ] 跑一遍实验 C 的自动模式，确认裁判和客户端能通：
      `python3 lab/game/referee.py --auto --rounds 2 --report-seconds 5 --discuss-seconds 3`
- [ ] 确认教室 Wi-Fi 允许设备互访；如果不允许，实验 C 改用"同一台电脑热座"或纯人工纸笔版。
- [ ] 准备大屏：一个终端窗口跑裁判，一个浏览器窗口开 `/board`。

### T-30 分钟

- [ ] 启动裁判：`python3 lab/game/referee.py --manual --rounds 5`
- [ ] 记下局域网 IP：`ipconfig getifaddr en0`（macOS）或 `hostname -I`（Linux）。
- [ ] 大屏打开 `http://localhost:8787/board`。
- [ ] 把 `http://<IP>:8787` 写在白板上，供学员连接。
- [ ] 摆好卡片、笔、计时器。

## 二、逐分钟 run-of-show

### 0:00–0:05 开场：一个问题

**动作**：举手投票。

**台词**：

> 先做个调查。你最近一次让 AI 做的事——写一段代码、查一组资料、改一份稿子——你能在 5 分钟内判断它做得对不对吗？
>
> 能的举手。不能的举手。没想过的举手。

**观察**：记下三组人数。复盘时用这组数据开头："开始的时候，能验收的人只有 X%。"

**不要做**：不要在这个环节讲 AI 趋势、模型能力、行业新闻。一句话都不要。

---

### 0:05–0:10 第一幕：吾不如子房、萧何、韩信

**动作**：念《史记·高祖本纪》那段话，只念一遍，不要解释太多。

**台词要点**：

> 刘邦当了皇帝，在洛阳南宫请群臣喝酒，问：我为什么能得天下？项羽为什么失天下？
>
> 然后他说：运筹帷幄，我不如张良；镇国家、给馈饷，我不如萧何；连百万之军，我不如韩信。这三个人都是人杰，我能用他们，所以取天下。项羽有一个范增，却不能用，所以被我擒。
>
> 这段话不是谦虚，是他在定义自己的工作：我的工作不是比他们强，是让他们为我所用。

**提问**：你上一次用 AI，是把它当"更快的自己"，还是当"一个需要被管理的团队"？

**收束**：刘邦的团队是一个多 agent 系统；项羽是一个单体模型。你用的是哪一个？

---

### 0:10–0:18 第二幕：萧何追韩信

**动作**：讲"国士无双"和"设坛拜将"，重点在"先问计划"。

**台词要点**：

> 韩信在项羽手下，官不过郎中，多次献策不用，跑了。到汉这边也不受重用，又跑了。萧何来不及报告，亲自去追。刘邦以为萧何也跑了，又怒又急。萧何回来说：诸将易得，韩信是国士无双。
>
> 刘邦说：那我让他当将军。萧何说：当将军，他还是要走。刘邦说：那就当大将。萧何说：幸甚。然后刘邦择良日、斋戒、设坛场，正式拜将。
>
> 拜将之后，刘邦第一句话不是"你去打"，是"将军何以教寡人计策"。韩信这才说出"汉中对"：项羽是匹夫之勇、妇人之仁，有功当封爵的人，印都刻好了，他捏在手里舍不得给。

**Agent 对应**：

> 你选 agent，不要只看榜单；让它在你的任务上说一遍计划，问它"你打算怎么打、哪里不确定、失败了怎么回滚"。给 agent 一个"坛"：清楚的角色、权限、输出格式、验收标准。

**提问**：你有没有因为一个 agent 在一次 demo 里表现好，就把一整类任务交给它？你有没有让它先说过计划？

**收束**：能力卡比印象可靠；拜将之前，先问对策。

---

### 0:18–0:23 第三幕：陈平盗嫂受金

**动作**：讲"用人如器"，快速带过，不要讲道德八卦。

**台词要点**：

> 陈平从项羽那边来投，有人告他盗嫂，又告他收将领的钱。刘邦责问。陈平说：我裸身来投，不收钱没有经费；我的计策有用你就用，没用，钱都在，我还给你，请辞。刘邦道歉，厚赐，拜他为护军中尉。
>
> 后来陈平献的都是奇计：离间项羽和范增、荥阳突围、伪游云梦擒韩信。不堂堂正正，但有用。

**Agent 对应**：

> 不同 agent 有不同"性格"：有的稳、有的快、有的会胡说、有的会过度自信。按任务选，不按"哪个最好"选。让"聪明但不可靠"的 agent 做创意、找漏洞、做红队，可以；让它直接碰不可逆操作，不行。

**提问**：你有没有因为一个 agent"风格不对"就弃用，却没试过把它放在它擅长的任务上？

**收束**：没有最好的 agent，只有最合适的编排。

---

### 0:23–0:31 第四幕：张良借箸代筹

**动作**：讲"印都刻好了"和"辍食吐哺"，这是全场最重要的一个故事。

**台词要点**：

> 郦食其劝刘邦复立六国后世，刘邦说好，印都刻好了。张良来见，刘邦把这事告诉他。张良问：谁给你出的这个主意？你的事要完了。刘邦问：为什么？张良借刘邦面前的筷子，一条一条数了八个"不可"。
>
> 刘邦听完，饭吐出来，骂人，立刻销印。

**Agent 对应**：

> 一个 agent 说"行"，不等于行。让它出一个方案，再让另一个 agent（或你自己）专门找反例。把"销印"做成流程：版本控制、草稿、沙箱、人工闸门。改起来越便宜，你越敢让 agent 跑。
>
> "从谏如流"在 AI 时代的版本是：CI 红灯就回滚，不要解释。

**提问**：你有没有过一次"印都刻好了"才发现方案不对？你当时是改，还是硬着头皮上？

**收束**：验收的核心不是"检查"，是"改得起"。

---

### 0:31–0:39 第五幕：白登之围

**动作**：讲"不听刘敬"和"回来后赦免、封赏刘敬"，重点在"异议通道"和"失败后的流程修复"。

**台词要点**：

> 刘邦要击匈奴，派刘敬出使。刘敬回来说：两国相击，本该夸耀武力，我只看到老弱和瘦马，这一定是诱敌，匈奴不可击。刘邦大怒，骂他"齐虏！以口舌得官，今乃妄言沮吾军"，把他关起来，亲自率军北上，结果在平城白登被围七日，靠陈平的秘计才脱身。
>
> 回来后，刘邦放了刘敬，说："吾不用公言，以困平城。"封他二千户，为关内侯。

**Agent 对应**：

> 你的 agent 团队里要有一个"刘敬"：专门说"可能不对"的那个。可以是另一个模型、一个红队 prompt、一个检查脚本。当所有 agent 都说"没问题"时，问一句："如果错了，最可能错在哪？"
>
> 失败后，不要只改输出；改那个让警告被忽略的流程。

**提问**：你身边有没有一个"刘敬"？他说话不好听，置信度不高，但他可能是对的。你上一次听他的建议是什么时候？

**收束**：刘邦赢了项羽，不是因为他从不犯错，是因为他犯错后改得快；白登的教训，不是"要听劝"，是"要给劝留一条能进来的路"。

---

### 0:39–0:46 提炼：三个工具

**动作**：发学员手册，带大家填一张能力卡（用他们自己的 agent，3 分钟）。

**讲解顺序**：

1. 能力卡：任务类型、3 个样本、失败模式、适用边界；四种角色：张良型、萧何型、韩信型、陈平型。
2. 委托深度 L1–L4：代查、代写、代做、代判；升一级的前提是多一条更便宜的验收。
3. 验收三件套：可执行、可证据、可回退。

**一句话**：

> 不是"越信任越要放权"，而是"越验得起越要放权"。

---

### 0:46–0:50 实验说明

**动作**：演示一遍最小命令，展示提交路径。

**台词**：

> 三条路线。A 萧何的粮道，一个人，15 分钟，修一个粮草分配器。B 汉营，四个人，25 分钟，各写一个模块再集成。C 白登，2 到 6 个人，每人一个 agent，5 轮突围。
>
> 90 分钟的课，我们做 A 和 C。B 是课后挑战。
>
> 规则只有一条：你可以让 agent 做任何事，但你要为结果签字。

**关键提醒**：

- A 的验收标准在 `ACCEPTANCE.md`，不在可见测试里。要不要把它给 agent，是你自己的管理决策。
- B 的军令是唯一真相；本地测试可能是错的。
- C 的置信度要诚实填；它不是策略，是校准数据。虚报高分只会让你在复盘时被点名。

---

### 0:50–1:10 实验 A：萧何的粮道

**讲师动作**：

1. 发工作区链接/二维码，确认每个人能打开 `lab/solo`。
2. 计时 15 分钟，在第 5、10 分钟各报一次时。
3. 第 15 分钟强制提交：把 `granary.py` 和 `criteria.md` 放到 `lab/solo/submissions/<名字>/`。
4. 助教用 `scoreboard.py` 收分；讲师继续带 C，不要等所有人。

**巡场时看三件事**：

- 学员的 brief 里有没有 `ACCEPTANCE.md` 的内容？
- 学员有没有让 agent 读隐藏测试或 `facilitator/`？（有就提醒：这是学习游戏。）
- 学员是不是在手动改 agent 的代码？记下人数，复盘用。

**常见卡点**：

- `pytest` 没装：用 `python3 -m pytest` 或直接 `python3 test_visible.py`；工作区里的 `selfcheck.py` 不依赖 pytest。
- 学员问"隐藏测试是什么"：回答"监军没给你看的那部分验收"。
- 学员提前做完：让他写 `criteria.md`，或去做 B。

---

### 1:10–1:25 实验 C：白登

**讲师动作**：

1. 大屏展示 `/board`，念一遍规则（1 分钟）。
2. 学员加入：`python3 client.py --server http://<IP>:8787 --name <名字> join`
3. 学员把 `agent_prompt.md` 贴进自己的 agent，替换服务器地址和名字。
4. 每轮：报告阶段（60 秒）→ 讨论阶段（45 秒）→ 揭晓（8 秒）。讲师按 Enter 推进。
5. 第 5 轮结束，展示最终排行榜。

**控场要点**：

- 报告阶段不要催；看 `/board` 上的"已提交"人数，到齐就推进。
- 讨论阶段让主将说一句"我们选哪条、为什么"，不要开放麦。
- 如果有人置信度全是 100，提醒一次："置信度是校准数据，不是气势。"
- 如果有人复探次数用完了还在问，告诉他："验收有成本，这就是这局的设计。"

**没有 agent 的学员**：

- 手动跑 CLI，或两人一组共用一台电脑。
- 纯纸笔版：每人发一张方向卡，写方向和置信度，讲师收齐后唱票；复探由讲师私下告知。规则不变，只是慢一点。

---

### 1:25–1:33 复盘

**动作**：大屏放三张表，先给数据，再提问。

**开场**：

> 开始的时候，能验收的人只有 X%。现在看三组数据。

**表 1：萧何的粮道**

> 只跑 pytest 的组，隐藏测试通过率是多少；把 ACCEPTANCE.md 贴进 brief 的组，通过率是多少。
>
> 这不是说"读文档就赢"，是说：你给 agent 的验收标准，就是它眼里的全部世界。

**表 2：汉营（如果做了）**

> 本地测试全绿，集成测试第一次过了几个场景？失败通常不在"谁写错了"，在"大家对单位的理解不一样"。

**表 3：白登**

> 看第一列准确率，第三列校准分。最准的人不一定最高分；置信度 90 但错三次的人，校准分很低。
>
> 这就是"项羽时刻"：说得越自信，错得越贵。
>
> 再看"刘敬时刻"：那个置信度最低、说"可能不对"的人，他答对了没有？团队听了吗？

**三个问题**（举手或点人）：

1. 你在哪一步把"我觉得对"当成了验收？
2. 你的 agent 在哪一步"自信地错"？你当时为什么信了它？
3. 如果重来一次，你会把哪一条验收标准写进 brief？

**收尾**（只说一次）：

> 刘邦赢了项羽，不是因为他每一仗都比项羽强。他自己说得很清楚：运筹不如张良，治国不如萧何，打仗不如韩信。他赢在能把这三个人放在对的位置上，并且在张良说"不对"的时候，立刻把印销掉。
>
> 你用 AI，不能假设自己身边有一个张良。你要么自己成为那个能听出"不对"的人，要么把"不对"做成一套谁都能跑的标准。前者靠判断力，后者靠工程。这堂课练的是后者；后续七集，练前者。
>
> 项羽有一范增而不能用。你有一个 agent 团队，你用了吗？

---

### 1:33–1:35 收尾

**台词**：

> 作业：选你本周最常做的一个任务，写一份 ACCEPTANCE.md，不超过一页。三条可执行检查，一条证据要求，一条回退方案。用你的 agent 跑一遍，记下它第一次失败在哪。下次带三样东西：验收标准、失败记录、你的能力卡。

## 三、讲稿的边界

- 不要花时间证明"AI 很强"。听众已经在用，不需要说服。
- 不要预测 AGI 时间表。无法验证，且会稀释主线。
- 不要把刘邦讲成完人。他杀功臣、猜忌萧何、白登轻敌；这堂课的力度来自"他会用人但也会犯浑，所以他需要一套能纠错的流程"。
- 不要用"赋能、闭环、抓手、对齐"这类词。说具体动作：写测试、跑命令、看日志、留备份。
- 不要承诺"学完就能管 agent"。承诺的是：你能给自己的任务定级，并写出第一条可执行验收。

## 四、应急预案

| 情况 | 处理 |
|---|---|
| 学员的 agent 连不上网络 | A/B 离线可做；C 改用同一台电脑热座，或纸笔版 |
| 学员没有 Python | 两人一组，用同伴的电脑；或只参加 C 的纸笔版 |
| 裁判启动失败（端口占用） | `--port 8788`；或 `lsof -i :8787` 杀掉旧进程 |
| 学员加入时重名 | 加后缀，如"韩信-2"；裁判会拒绝重名 |
| 学员读裁判源码找答案 | 提醒一次；不惩罚，但复盘时请他解释"知道了答案，你学到了什么" |
| 时间超时 10 分钟 | 砍掉实验 B 的复盘，保留 A 和 C 的数据；作业里补 B |
| 人数超过 20 | 实验 A 全员做；C 分 3–4 桌，每桌 5 人，助教当裁判；或只做 A + 大屏演示一局 C |
| 冷场，没人提问 | 用卡片收集问题，抽三张念；或让邻座互相说 1 分钟"我最近一次返工" |
