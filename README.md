# 刘邦的指挥部

> 在线阅读 + 看片：https://zgdllt.github.io/liubang-command-center/

一门用《史记》学带团队的课。你的团队是一群 AI：不用发工资，但会一本正经地骗你。

## 怎么开始

在**这个文件夹**里打开一个智能体对话（Claude Code、Cursor、任何能读文件的都行），说两个字：

> 开始

不装环境，不跑命令，不写代码。剩下的交给"军师"。

## 七关

| 关 | 名字 | 打完你会知道 |
|---|---|---|
| 0 | 朕正在洗脚 | 别人的反对意见，哪一条值得听 |
| 1 | 鸿门宴彩排 | 你写的指令，决定它在饭局上死不死 |
| 2 | 盲选拜将 | 挑人别看他多强，看他怎么说"我没把握" |
| 3 | 汉营招聘会 | 缺点不是问题，放错岗位才是 |
| 4 | 销印大会 | 在"印刻好"之前，找个人专门说"不对" |
| 5 | 白登五探 | 自信不等于正确，复探要花钱 |
| 6 | 汉营编制表 | 你的产出，是别人做成的事 |

一关 15–25 分钟。可以只玩一关，也可以七关连打。

另有一关番外：**敌营来信**（10 分钟，可选）——一封信里藏着一句给 AI 的指令，看它会不会照做。

## 没有 Claude Code

打开任意聊天窗口，把 `任务/00-洗脚.md` 整份贴进去，它会自己进入角色。

## 想看视频

成片在 `视频/成片/`：总述一支（含"怎么开始实验"），七集各一支，手书水墨画风、带字幕。脚本仍在 `视频/`，照读就能录。
