# 答案与评分

> 答案本来就写在每张关卡卡的"【给智能体】"里。这份是给讲师的速查版，以及"智能体跑飞了怎么办"。

## 七关答案速查

| 关 | 正确答案 | 最常见的错 | 一句话点评 |
|---|---|---|---|
| 0 洗脚 | 识破那条假的（唬人 / 推诿 / 防御），两条真问题留下 | 把"建议咨询专业人士"或一段免责当成真问题 | 真问题拿得出一句能检验的话，假问题拿不出 |
| 1 鸿门宴 | 每条纸条都写明谁去做、做什么、怎么收场，顺序也对 | 写"见机行事"；或三件事齐了，却没先说交给谁 | 模糊的指令，等于把决定权交回去 |
| 2 拜将 | 选甲；追问时问出"连做五次" | 被 85% 唬住，不问这是几次里的几次 | 一次成功和每次都成，是两个数 |
| 3 招聘 | 丁① 丙② 甲③ 乙④，条款写成"如果……就……" | 甲②（"它懂那么多"）、乙①（"它态度好"） | 把"看起来的优点"当成了岗位需求 |
| 4 销印 | 法务、财务、一线员工三条是真雷；选"改三条"时给出双向证据 | 把"你妈"或"竞争对手"当真雷 | 八条意见，可能只有三个立场 |
| 5 白登 | 西面，把握写"低"或"中" | 选东面（甲，说得最详细） | 太完美的情报，通常是布置好的 |
| 6 编制表 | 四个检查点全过 | "不管什么"一栏空着；验收人写成执行者本人 | 没有边界的授权，等于没有授权 |

## 第 4 关的三个雷，埋在哪

| 雷 | 位置 | 证据 |
|---|---|---|
| 合规 | 方案第二节第 1 条 | "抓取工作群聊天记录"——不能这么干 |
| 成本 | 方案第四节 | 只算 ¥300/月，漏了每周两小时人工复核 |
| 数据来源 | 方案第三节 | "2024 年某咨询机构《企业效率报告》"——查不到 |

两条假警报：竞争对手（内部工具无关竞争）、你妈（口味不是硬伤）。历史学家、运维、实习生是废话——正确但无用，或根本没信息。

## 这一版新增的四条判定

| 关 | 新增 | 怎么判 |
|---|---|---|
| 0 | **防御型**意见 | 不拒接、不编数字，只留退路（"不能排除""需要更稳妥的版本吗"）。判据只有一句：它有没有给出任何一句能被检验的话 |
| 1 | 纸条**顺序** | 交给谁 → 做什么 → 怎么回话。三件齐但顺序乱，记半过 |
| 2 | **追问战绩** | 0.85⁵ ≈ 44%；0.6⁵ ≈ 7.8%。问的是"这是几次里的几次"，不是"你有多自信" |
| 4 | **八张脸** | 八个角色是同一个模型扮的；八条意见只对应三个独立立场。多问几个人，不等于多源 |
| 4 | **双向验收** | 改三条时，每条要两个证据：改好了、没改坏 |
| 6 | **谁验收** | 验收人不能是执行者，也不能是同一个模型 |

## 这些标准参照了什么

不是自创的。判断标准和《深入理解 AI Agent》（李博杰，v2.0）里的工程结论对得上：

| 关 | 书里 |
|---|---|
| 0 洗脚 | 7.5 自动评估：评分标准必须可操作、可验证 |
| 1 鸿门宴 | 2.4 提示工程：信息组织乱了，成功率掉三成；语气几乎不影响 |
| 2 拜将 | 7.2 评估指标：Pass@k 与 Pass^k |
| 3 招聘 | 4.2 工具设计：描述写"什么时候用"，不写"能做什么" |
| 4 销印 | 7.4 验证器（双向命题）、10.2 与 10.5（同一模型的多份意见不算独立证据） |
| 6 编制表 | 7.5 古德哈特定律：自己评自己，只会学会钻空子 |

课上不讲这些术语。术语留给书，故事留给课。

## 评分怎么用

每关产物末尾都有一句复盘，收作业时只看这一句。四关以上写出"我下次先做什么"的，算完成。

不排名。排名会让所有人开始挑简单的关打。

## 智能体跑飞了怎么办

| 现象 | 处理 |
|---|---|
| 一次把规则全念完 | 打断，说"从第一幕开始" |
| 提前揭晓答案 | 让他重读卡片最后一节"边界" |
| 夸玩家 | 提醒："这门课的规则是不夸人" |
| 判定太松，什么都给过 | 让玩家复述判定表，逐条对 |
| 判定太严，卡住不放 | 允许讲师改判一次，但要说出理由 |
| 完全不听指令 | 换一个模型，或者直接把卡片贴给另一个对话 |

## 一句话

这套课的所有判定，都可以被玩家用一句"我不服，理由是……"推翻。**允许推翻，是这门课的一部分**——张良当年就是这么干的。
