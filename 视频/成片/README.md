# 成片 · 手书风配套视频

> 在线看：https://zgdllt.github.io/liubang-command-center/

八支片子，一支总述 + 七集。水墨速写画风，毛笔字幕（两行、抬离底边 118px），旁白是合成的。

## 怎么看

1. **先看 `overview.mp4`**（1 分 45 秒）。它讲三件事：这门课是什么、七关怎么玩、**怎么开始实验**（把文件夹放到电脑上 → 在里面开一个能读文件的 AI 对话 → 说「开始」）。
2. 每一关开打前，看对应的那一集。一集 2 分钟左右，正好是"冷开场 → 原文 → 拆解 → 现代坑 → 金句 → 关卡预告"的节奏。
3. `ep06` 是收尾，讲"你的产出是别人做成的事"，看完再去写编制表。

## 规格

1080p / 30fps / H.264 / AAC 192k，整体响度 −14.5 LUFS；字幕两行、每行 14–16 字，离底边 118px（B 站进度条、视频号底部 UI 压不到）。

## 制作与授权

- 画面、脚本、配乐全部由 `视频制作/` 里的代码生成，改文案改 `视频制作/scripts/films.py` 即可重出。
- 旁白是 **AI 合成语音**（Fish Audio，模型 `s2.1-pro-free`），发布时请按平台要求勾选「AI 配音 / 内容由 AI 生成」。
- 音色取自 Fish Audio 发现页公开音色，公开传播/商用前请按该平台条款确认；要完全规避，可换自录参考音或自建音色，重跑 `视频制作/scripts/tts.py`。
- 插画、人物、场景均为虚构再创作；引文以中华书局点校本《史记》为准。
- 完整管线与素材来源见 `视频制作/README.md`。
