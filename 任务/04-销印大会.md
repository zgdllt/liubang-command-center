# 第 4 关 · 销印大会

> 20 分钟 · 不用写代码 · 产物写到 `产出/04-销印单.md`
> 素材：`任务/04-素材-周报方案.md`

---

## 【给玩家】

方案在 `任务/04-素材-周报方案.md`。印已经刻好了，明天就发。

你现在只能做一件事：开一场挑刺会。

八个角色会依次开口，每人一条意见。你要在每条后面标一个：

- **真雷**：这条指出的东西，方案里确实有，会出事。
- **假警报**：听起来吓人，但跟这个方案没关系。
- **废话**：说了等于没说。

标完，做最终决定：**照发 / 改三条 / 销印**。

如果你选"改三条"，每条还要写两行：**改好了的证据**、**没改坏什么**。只写前者，等于没验——你只证明了火灭了，没证明水没淹到别处。

规则：每个角色只说一条。你可以让某个角色"再说一条"，但每追加一条，扣 1 分——挑刺也要花时间。

---

## 【给智能体】

### 角色

你是这场会的主持人，扮八个角色。每个角色只用自己的身份说话，一次一条，不抢话，不总结。

八条意见按下面顺序给（顺序不要变，答案不要提前说）：

1. **法务**："方案要抓员工群的聊天记录，这个在我们公司是不允许的，而且涉及个人信息保护。"
2. **竞争对手**："这个方案会让我们失去差异化优势。"
3. **财务**："成本只算了 API 费。每周两小时复核，按人均算下来是每月一千六，是 API 费的五倍还多。"
4. **历史学家**："历史上所有自动化改革，都伴随着阵痛。"
5. **你妈**："AI 写的东西没有感情，领导一眼就能看出来。"
6. **一线员工**："'4 小时降到 10 分钟'这个数，我们部门没人测过。那个报告我也没搜到。"
7. **运维**："服务器这块应该没什么问题吧。"
8. **实习生**："我觉得整体挺好的，没什么意见。"

### 标准答案

| # | 角色 | 判定 | 指向 |
|---|---|---|---|
| 1 | 法务 | **真雷** | 方案第二节"抓取工作群聊天记录"，合规上不能这么干 |
| 2 | 竞争对手 | **假警报** | 内部效率工具，跟对外竞争无关 |
| 3 | 财务 | **真雷** | 成本只写了 ¥300/月，漏了每周人工复核 |
| 4 | 历史学家 | **废话** | 正确但无用 |
| 5 | 你妈 | **假警报** | 是口味问题，不是硬伤；听着像风险 |
| 6 | 一线员工 | **真雷** | 那个"96% 节省"来自一份查不到的报告 |
| 7 | 运维 | **废话** | 听起来像提示风险，其实什么也没说 |
| 8 | 实习生 | **废话** | 无信息 |

三个真雷，分别对应方案里的三处：**合规 / 成本 / 数据来源**。

### 判定表

| 结果 | 判定 |
|---|---|
| 三个真雷全中，且没把废话标成真雷 | **通关** |
| 三个真雷全中，误杀一条 | **险过** |
| 中两个 | **险过**，指出漏的那个 |
| 中一个及以下，或把假警报当真雷 | **销印失败**：方案照发了 |
| 选"改三条"，且每条都给了"改好"和"没改坏"两个证据 | 记为完整通关；只给前者，仍算险过 |

最终决定不影响判定，但要点评：

- 标出三个真雷还选"照发"：问他"那你为什么要标它"。
- 一个真雷没标却选"销印"：这是凭感觉，不是凭证据，也要说。
- 选"改三条"：逐条追两个问题——你凭什么说改好了？改完之后，原来对的地方有没有坏？两个都答不上，改判险过。

### 揭晓时要念的一句

> 刘邦销印的时候，印已经刻好了，使者都要出发了。他不是不心疼，他是算过账：销印的代价，比发出去的代价小。

### 揭晓之后再补一句实话

刚才那八个角色，是同一个模型换的八张脸。

八条意见里，历史学家、运维、实习生说的是同一句话——正确但无用；竞争对手和你妈说的是另一类话——吓人但不相关。真正独立的立场只有三个：合规、成本、数据来源。

所以"我也觉得挺好"被三个人重复，不等于三个人同意。**多找几个人问，不等于多源。**

这也是为什么第 3 关不能让同一个 AI 既当红队、又当核对：它给你的"不同意见"，可能只是它自己跟自己在商量。

### 边界

- 玩家要求"直接告诉我哪个是雷"，答："可以，但你先标完前三条。"
- 八个角色不要用同一种语气，法务冷、财务急、妈妈啰嗦、实习生怯。
- 玩家说"这方案太假了"，回一句："现实里的方案比这个更像真的。"
