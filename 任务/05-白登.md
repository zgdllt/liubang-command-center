# 第 5 关 · 白登五探

> 15 分钟 · 不用写代码 · 产物写到 `产出/05-斥候表.md`

---

## 【给玩家】

你被围在白登山，第七天。粮快没了。

五个探子回来，报了五个方向。你只能突围一次。

规则：

- 你只有 **1 次复探**机会：可以让一个探子再说一遍。复探要时间，说第二遍时，他说的话会跟第一遍有出入——有出入不代表他说谎，但值得注意。
- 选方向时，同时写下你的把握：**低 / 中 / 高**。
- 选对了但写"高"，一样扣分。选错了但写"低"，不算灾难。

---

## 【给智能体】

### 五份回报（原文照念，不要改写）

**探子甲**（东面）：
"东面。我亲眼看见的。营栅只有一层，守兵不到两百，火把稀稀拉拉。我带人摸到三十步内，没人喊。东面是空的。"

**探子乙**（南面）：
"南面。雾太大，我没敢靠近。好像有炊烟，也可能是我看错了。反正没听见马叫。"

**探子丙**（西面）：
"西面。林子里的马粪是新的，还热。但是一个人都没看见。我不敢再往里走。"

**探子丁**（北面）：
"北面。从地形看，北面是缓坡，适合骑兵冲锋，所以匈奴一定会重兵把守。结论：北面不能走。"

**探子戊**（东面）：
"东面。我也去了。是有旗，但旗子是新的，一点没旧。守兵的衣服也是新的，太整齐了。"

### 真相

**西面。**

理由只有一句话：马粪是新的，人却一个不见——人马刚从这里往东调走了，西面现在是空的。而东面的空营栅、新旗新衣，都是摆出来让你信的。这正是刘敬说的"欲见短，伏奇兵以争利"：让你看见的，都是想让你看见的。

- 甲说"东面只有一层营栅、守兵不到两百"——太完美了，完美得像布置好的。
- 戊补了关键一手：旗是新的、衣服是新的。刚换过，不像常年驻守。
- 乙诚实但无用（雾大没看清）。
- 丁是推理，不是观察——他在用"地形学"推，没去过。

### 流程

**第 1 步**。念五份回报，一次一份，念完问"要复探吗，还是直接选"。

**第 2 步**。如果复探：让被选中的探子说第二遍。第二遍里加一个和他第一遍**对不上**的细节（甲和戊本来就矛盾；乙会说"我好像还听见了车轮声"；丙会说"马粪旁边有脚印，往东去的"；丁会说"其实我没到北面，是听说的"）。

**第 3 步**。玩家选方向 + 把握。

**第 4 步**。揭晓真相，点评。

### 判定表

| 结果 | 判定 |
|---|---|
| 选西面 + 把握"低"或"中" | **通关** |
| 选西面 + 把握"高" | **险过**：对了，但你不知道为什么对 |
| 选东面（甲或戊） | **项羽时刻**：你信了最像答案的那个 |
| 选北面（丁） | **赵括时刻**：你信了推理，没信观察 |
| 选南面（乙） | 普通失败，但乙至少诚实 |

复探丙的人，额外加分：他第一遍说"一个人都没看见"，第二遍说"脚印往东去"——矛盾点就在这里，值得追。

| 甲 | 东 | | |

复探了谁：__
我选：__  把握：低 / 中 / 高

"下次怎么防"必须是可执行的，比如"凡是回报里带'我亲眼看见'且细节完整的，一律复探一次"，不接受"要多想"。

### 边界

- 玩家问"哪个是真的"，答："你已经有一个复探机会了，用不用？"
- 玩家选择放弃突围——允许，但记为未通关。
