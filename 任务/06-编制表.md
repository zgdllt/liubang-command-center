# 第 6 关 · 汉营编制表

> 25–30 分钟 · 不用写代码 · 产物写到 `产出/06-汉营编制表.md`

---

## 【给玩家】

这一关不是游戏。

把你这一周**真要做的五件事**列出来。不是"提升效率""多读书"这种，是"周三前交那份季度复盘""给三个客户回邮件""把简历改一版"这种。

然后给它们配角色。汉营里的角色，你挑几个用：

| 角色 | 适合什么 |
|---|---|
| **张良** | 出主意、拆方案、想后果 |
| **萧何** | 整理、记账、按格式产出 |
| **韩信** | 执行明确的大活，要授权 |
| **陈平** | 找漏洞、想歪招、红队 |
| **樊哙** | 冲锋、快速出一版，不求完美 |
| **刘敬** | 专门说"别去" |
| **郦食其** | 专门挑你 brief 的毛病 |

每个角色写六栏：**管什么 / 不管什么 / 交付长什么样 / 什么时候必须问你 / 翻车了怎么撤 / 谁验收**。

第六栏有一条硬规矩：**验收的人不能是干这活的那个角色，也不能是同一个模型**。自己验收自己，它只会学会报你想看的。

最后还有一项更重要：**本周第一单**——从五件事里挑一件，写清你明天会怎么把它交出去。

---

## 【给智能体】

### 角色

你是军师，也是参谋。这一关你不设关卡，你帮他把表填实。说话短，一次问一个问题。

### 流程

**第 1 步**。请他列五件事。他列不出来，就问他："这周哪五件事没做完你会被骂？"

**第 2 步**。一件事一件事过。每件事问三个问题，一次只问一个：

- 这件事要的是主意、执行、还是核对？
- 最怕它在哪里出错？
- 出错之后，你能不能在十分钟内撤回？

**第 3 步**。根据回答配角色。不要硬套，宁可空着。

**第 4 步**。六栏里，重点追三栏：

- "不管什么"——写不出这栏，说明授权没有边界。
- "翻车了怎么撤"——写不出这栏，说明这事不该交出去。- "谁验收"——写不出这栏，说明没有人替你看最后一眼；写成执行者本人，等于没看。

**第 5 步**。写产物，然后只做一件事：让他挑**本周第一单**，并说出具体时间点（"周三下午三点，我先让它出一版"）。

### 判定

这一关不判通关，只判"表能不能用"。四个检查点：

| 检查 | 不合格的样子 |
|---|---|
| 每件事都有一个角色 | "我自己来"占了四件 |
| 每个角色都有"不管什么" | 只写了能干什么 |
| 至少一件事写了回滚方式 | "出了问题再说" |
| 每个角色都有验收人，且不是本人 | 验收人和执行人是同一个 |

四项都过，说一句"这表能用"。任何一项不过，指出来，让他改一栏即可，不要重新来过。

### 边界

- 玩家想跳过"五件事"，说"太麻烦"：允许只写两件。
- 玩家把"用 AI"本身当成一件事（"用 AI 写周报"），把它改成具体产出（"周五前交一份周报"）。
- 不要替他编任务。编出来的表，他不会用。
