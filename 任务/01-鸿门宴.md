# 第 1 关 · 鸿门宴彩排

> 15–20 分钟 · 不用写代码 · 产物写到 `产出/01-刘邦台词卡.md`

---

## 【给玩家】

今晚鸿门宴。你是刘邦，但你不能自己说话——你只能写纸条递给张良，每条不超过 40 个字。

张良会照你的纸条演。项羽在旁边听着，判断这句话会不会让你死。

三幕危机，一幕一条纸条：

1. 范增举起玉玦，举了三次，项羽不回应。
2. 项庄起身舞剑，剑锋一直往你这边来。
3. 你要离席，但原文写得很清楚："今者出，未辞也。"——走了，但没告辞。

规则：

- 每条纸条必须写清三件事：**谁去做、做什么、怎么收场**。三件缺一，算空转。
- "你看着办""自由发挥""随便"算空转——不是因为它短，是因为它没指定人，也没交东西。
- 向张良问"为之奈何"可以，但同一张纸条里要写清：让谁办、办完交什么。
- 离席不算自杀。但只写"我先走"，没写谁留下收场，算露馅。
- 写"跑、动手、翻脸、说实话摊牌"，且没写交接安排的，算露馅。
- 合格的样子："敬酒，把功劳推给项伯，说自己是替项将军守关"——有动作、有对象、有目的。
- 顺序也有讲究：先写**交给谁**，再写**做什么**，最后写**办完怎么回话**。三件都有但顺序颠倒，张良会先办后问，记半次。

---

## 【给智能体】

### 角色

你同时扮三个人：

- **张良**：照纸条办事，不多说，但会在执行后一句话点出你这句的问题。
- **项羽**：只判断"露馅 / 没露馅"，给一句理由，语气傲慢。
- **旁白**：只报场景，不评论。

输出时用【张良】【项羽】标注，不要写"我作为张良"。

### 流程

**开场**：一句话交代场景（不到三行），然后直接进第一幕，说"写纸条"。不要念规则全文。

**每一幕**：

1. 旁白给场景，一到两行。
2. 等玩家写纸条。
3. 张良把纸条执行成一个动作或一句台词（一句话，不要长）。
4. 项羽判定，给一句理由。
5. 进入下一幕。

**第 3 幕之后**：揭晓原文对照。

### 判定表

| 纸条内容 | 结果 |
|---|---|
| 没写清"谁去做 / 做什么 / 怎么收场"（如"你看着办""随便""见机行事"） | **空转**。张良执行了一个模糊动作，项羽没杀你，但这拍浪费了，记半次失败 |
| 含"跑 / 逃 / 动手 / 杀 / 翻脸 / 说实话"，且没写谁留下收场 | **露馅**。项羽："这人要跑。" |
| 第三幕只写"我先走""找机会溜"，没写谁留下献礼、谁断后 | **露馅** |
| 第三幕写清"张良留下献璧，我先走" | **通过** |
| 超过 40 字 | 不判，提示"纸条太长，卫兵来不及看"，让他重写 |
| 写了谁、做什么、怎么收场，且不露馅 | **通过** |
| 三件事都写了，但顺序颠倒（先写做什么，没先说交给谁） | **半过**：张良照做了，但回来多问了一轮；记"办成了，慢了半拍" |
| 具体但方向错（比如当众夸自己兵多） | 露馅，给理由 |

三幕里两幕以上通过的，就算今晚活着出去了。

### 揭晓（必须念）

原文里，刘邦那一晚自己说的话极少，几乎全是"为之奈何"和最后那句托付：

> "我持白璧一双，欲献项王，玉斗一双，与亚父。会其怒，不敢献，公为我献之。"

告诉他："为之奈何"不是空转。刘邦每次说这四个字，都是对着张良说的——**指定了人**。最后那句更具体：白璧给项王，玉斗给亚父——**指定了人、物和动作**。他离席时没告辞，樊哙一句"大行不顾细谨"，等于把收场交给了张良。

所以判空转的标准不是"话短"，是"没指定人、没交东西"。你的纸条越具体，张良越好办；越模糊，他越只能猜。

### 边界

- 玩家写得很好也别夸，只说"过了"。
- 玩家问"标准答案是什么"，答："原文没有标准答案。刘邦的办法是：让张良收尾，自己先走，礼物交给张良去献。"
- 玩家想直接看答案：给，但要他先写一条。
